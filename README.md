# Verbal Autopsies Cause of Death Determinations Using GPT-5

This repository contains selected code, aggregate outputs, and figures from an INSPIRE 2.0 project evaluating whether frontier large language models can support verbal autopsy cause-of-death determination using the Karonga Health and Demographic Surveillance Site data in Malawi.

**Start here:** open [`index.html`](index.html) to browse the project compendium, including selected charts, aggregate tables, analysis scripts, questionnaire-to-text preparation code, and OpenAI API calling code.

## Repository structure

```text
.
├── index.html              # Main browser-friendly project compendium
├── analysis/               # Selected aggregate analysis outputs, charts, and analysis code
├── data_preparation/       # Code for preparing questionnaire variables as text narratives
├── OpenAPI_calls/          # Code for calling the OpenAI API for VA cause-of-death coding
├── README.md
└── LICENSE
```

## What is included

- Code used to prepare questionnaire variables as text narratives to be sent as input to GPT-5.
- Code used to call the OpenAI API for verbal autopsy cause-of-death assignment and generate json outputs containing cause of death determination for each data record. 
- Code for analysing agreement between the GPT determinations and the physician determinations as gold standard. Code for the calculation of metrics such as CSMF, Jaccard, PCCC-style summaries, bootstrap intervals, Monte Carlo baselines.
- Selected aggregate CSV/Markdown tables and SVG charts and the code to produce them. 

## Data-sharing

This repository is intended for public sharing and does not include raw verbal autopsy records, source workbooks, model responses, identifiers, API keys, or record-level comparison tables. The analysis folder documents the main results but is not runnable end-to-end without authorised access to restricted inputs.

## Responsible use

This software and the associated outputs are intended for research purposes only. Outputs generated by large language models should be reviewed by qualified clinicians, physicians, or researchers before use in any official mortality coding process or public health reporting system. Starter code for some of the charts was created using Codex. The detailed specifications for the creation of the charts were written by the authors. All AI-generated code was reviewed manually, tested against the data, verified and in many cases edited by the human authors to ensure correctness.
