# Verbal Autopsies Cause of Death Determinations Using GPT-5

This repository contains selected code, aggregate outputs, and figures from an INSPIRE 2.0 project evaluating whether frontier large language models can support verbal autopsy cause-of-death determination in the Karonga Health and Demographic Surveillance Site, Malawi.

**Start here:** open [`index.html`](index.html) to browse the project compendium, including selected charts, aggregate tables, analysis scripts, questionnaire-to-text preparation code, and OpenAI API calling code.

## Repository structure

```text
.
├── index.html              # Main browser-friendly project compendium
├── analysis/               # Selected aggregate analysis outputs, charts, and analysis code
├── data_preparation/       # Code for preparing questionnaire variables as text narratives
├── OpenAPI_calls/          # Code for calling the OpenAI API for VA cause-of-death coding
├── README.md
└── LICENSE
```

## What is included

- Analysis code for agreement, CSMF, Jaccard, PCCC-style summaries, bootstrap intervals, Monte Carlo baselines, and chart generation.
- Selected aggregate CSV/Markdown tables and SVG charts.
- Code used to prepare questionnaire variables as text narratives.
- Code used to call the OpenAI API for verbal autopsy cause-of-death assignment.

## Data-sharing boundary

This repository is intended for public sharing and does not include raw verbal autopsy records, source workbooks, model responses, identifiers, API keys, or record-level comparison tables. The analysis folder documents the workflow but is not runnable end-to-end without authorized access to restricted inputs.

## Responsible use

This software and the associated outputs are intended for research purposes only. Outputs generated by large language models should be reviewed by qualified clinicians, physicians, or researchers before use in any official mortality coding process or public health reporting system.
